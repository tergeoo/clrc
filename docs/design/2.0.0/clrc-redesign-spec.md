## Принятые решения по открытым вопросам

1. Входящие и Проекты — две вкладки. Альтернатива с переключателем «По статусу / По проектам» — вариант 1c.
2. Терминал — режим сессии и проекта, не отдельная вкладка.
3. Merge MR — в меню «···» с подтверждением; на панели — Approve и Комментарий.
4. Ответ из Входящих уходит сразу, тост «Отменить» 3 с.
5. iPad split-view — следующий этап.
6. В макетах 2 Мака; уровень «Маки» пропускается, если Мак один.

## Визуальная система

- Таб-бар: Входящие · Ревью · Проекты · Настройки.
- Статусы везде одинаковые: ждёт ответа — оранжевый `?`, ошибка — красный `!`, работает — синий (кольцо с точкой), готово — зелёный `✓`, неизвестно / idle — серый. Всегда иконка + текст.
- SF Pro для интерфейса, SF Mono для путей, команд, инструментов, кода.
- Код, diff и терминал — всегда тёмная палитра (`#1C1C21`).
- Карточки: радиус 12, отступ 12; тап-зоны ≥ 44 pt; основные действия в нижней трети.
- Опасные действия — красным, отдельно (опасная зона в Настройках, ^C в терминале).

## Экраны

### 5.1 Вход — `Onboarding` (`state`: start | manual | error)
- Иконка, название «clrc», одна фраза.
- Главная кнопка «Сканировать QR с Мака», подсказка `clrc pair`, ссылка «Ввести вручную».
- Ручной ввод: Relay URL (моно, URL-клавиатура) + пароль; «Войти» над клавиатурой.
- Ошибка пароля — красная рамка и текст под полем.

### 5.2 Входящие — `Inbox` (`variant`: a | b | c; `state`: normal | answered | offline | empty | loading; `dark`)
- Заголовок + пилюля связи («2 Мака» / «нет связи») + строка-сводка «2 ждут вас · 2 работают · 1 готово».
- **1a По срочности** (основной): секции Ждёт вас → Работает → Готово → Терминалы. Карточка: иконка статуса, title, summary (2 строки), мета `проект · Мак · N файлов`, точка контекста, до 2 кнопок ответа + «···».
- **1b Триаж**: три счётчика, крупная карточка «Следующее» с большими кнопками, остальное плотным списком.
- **1c По проектам**: переключатель «По статусу / По проектам», группы по проекту с «＋» (новая задача в проекте), кнопки ответа внутри строк.
- Работающие сессии: текущий инструмент (`Edit src/routes/login.tsx`) и таймер хода.
- FAB «Новая задача» справа внизу.
- Состояния: ответ отправлен (карточка уходит в «Работает», тост с «Отменить»); нет связи с relay (баннер + «Повторить», карточки приглушены, ответы неактивны, метка «mac-mini не в сети»); пусто («Нет сессий», кнопка, недавние проекты с запуском в 1 тап); загрузка (скелетоны); тёмная тема.

### 5.3 Новая задача — `NewTask` (`focused`, `dark`)
- Шторка: Мак (чипы) → Проект (недавние + «Выбрать папку…») → Задача (поле, необязательно, + микрофон, шаблоны) → Режим Chat / Brief / Terminal с пояснением → «Дополнительно» (имя, модель, профиль).
- Внизу «Запустить в <проект>» и «Пустой терминал».
- Фокус на поле: шторка растёт, Мак/проект/режим сворачиваются в строку чипов, панель над клавиатурой: спрятать, микрофон, «Запустить».

### 5.4 Сессия: чат — `Chat` (`variant`: chat | brief | pinned; `keyboard`; `state`: idle | working | error; `dark`)
- Шапка 44 pt: назад, имя сессии, `путь · режим ▾`, точка контекста, бейдж «работает».
- Лента: сообщение пользователя, строка инструментов «7 действий · Read ×3 · Edit ×2 · Bash ×2», markdown с блоком кода («Копировать»), карточка итога.
- Карточка итога: статус, стоимость и время, title, summary, блок «4 файла · +86 −31 · Diff ›» со списком путей, «Дальше: …», вопросы — крупные кнопки 1/2.
- **2a Chat**: текст, затем итог. **2b Brief**: итог первым, текст свёрнут в «Подробности». **2c Закреплённый итог**: вопрос и кнопки ответа всегда над полем ввода.
- Нижняя панель (чтение): чипы Продолжай / Да / Нет / Покажи diff / Запусти тесты / Закоммить; пилюля «Ответить…», микрофон, «Стоп» во время работы.
- Режим ввода: шапка 32 pt, одна строка над клавиатурой — спрятать, ＋ (путь файла / шаблоны), поле, отправить. Ввод + клавиатура ≈ 46 % высоты. После отправки клавиатура закрывается.
- Состояния: работает (текущий инструмент и таймер в ленте); ход прерван (красная карточка, «Повторить», «Сжать и продолжить»); тёмная тема.

### 5.6 Терминал — `Terminal` (`keyboard`; `state`: normal | reconnect | ended)
- Просмотр: 13 pt моно, клавиатура скрыта, пути подчёркнуты (тап → файл), бейдж размера шрифта.
- Нижняя панель: «⌨︎ Клавиатура», ^C (красным), ↑ история, «Команды».
- Ввод: одна строка спецклавиш Esc Tab Ctrl (залипающий) ↑ ↓ ← → | ~ / - и «спрятать», под ней тёмная клавиатура (en).
- Состояния: «Переподключение…» (ввод заблокирован), «Сессия завершена» + «Перезапустить».

### 5.7 Ревью — список — `ReviewList` (`tab`: claude | gitlab; `state`: normal | empty | nogitlab; `dark`)
- Сегменты «От Claude» / «GitLab», фильтр по проектам.
- GitLab: фильтры «Назначены мне / Мои / Все»; строка MR — заголовок, `!номер`, проект, автор, ветки, пайплайн (✓ / ✕ / идёт), обсуждения, +/−; «Просмотренные» свёрнуты.
- От Claude: ходы с изменениями — title, проект, номер хода, файлы, +/−, метка (ждёт ответа / новое / просмотрено).
- Состояния: «Подключите GitLab» (кнопка в настройки), «Нечего ревьюить».

### 5.8 Обзор MR / изменения хода — `MergeRequest` (`kind`: gitlab | claude; `dark`)
- GitLab: заголовок, автор, ветки, пайплайн (тап → джобы), описание (свёрнуто, «Ещё»), сводка файлов и обсуждений, «Попросить Claude сделать ревью».
- Файлы: прогресс «7 из 12», бейджи A / M / D, +/−, отметка «просмотрен», метка обсуждений; lock-файлы и сгенерированное скрыты.
- Нижняя панель: Approve · Комментарий · «···» (Merge, Закрыть, Открыть в браузере).
- Ход Claude: тот же экран без GitLab; «Принять» · «Попросить исправить» · «···» (откатить файл).

### 5.8 Diff файла — `Diff` (`orientation`: portrait | landscape; `device`: max | se; `comment`)
- Шапка: имя файла, путь, статус, +/−, поиск, размер шрифта; панель «Перенос ✓», Unified/Split, «файл 3 / 12».
- Unified: номера old/new, фон строк +/−, подсветка синтаксиса, word-diff внутри строки, заголовки ханков, свёрнутые участки «⋯ 42 строки · +20 · всё», мини-карта справа.
- Обсуждение между строк: автор, текст, «Ответить», «Решить», «Спросить Claude».
- Низ: ‹ ханк 2/5 ›, «Просмотрен», «Файл ›».
- Комментарий: тап по строке → строка подсвечена, шторка с превью строк, поле, «Предложить правку», «Спросить Claude», клавиатура.
- iPhone SE: 11.5 pt, узкие номера. Ландшафт Pro Max: split (старое | новое), компактные комментарии.

### 5.9 Проекты — `Projects` (`level`: macs | mac | project | picker; `dark`)
- Маки: карточки с онлайн/офлайн, числом сессий, профилем; «Подключить ещё Мак».
- Проекты Мака: поиск, недавние — имя, путь, ветка, «грязное» состояние, число сессий; «Все папки…».
- Проект: «Новая задача здесь», «Терминал здесь»; секции Сессии, Изменения (git status → diff), Файлы (поиск, «···» для создания и удаления).
- Выбор папки: хлебные крошки, список папок, «Выбрать «tools»».

### 5.10 Просмотр файла — `FileViewer` (`search`, `truncated`)
- Подсветка, номера строк, поиск с «2 из 5» и ↑↓, подсвеченные совпадения.
- Плашка «Файл обрезан: первые 100 КБ».
- Низ: «Копировать путь», «Спросить Claude», `$_` (открыть в терминале).

### 5.11 Настройки — `Settings` (`dark`)
- Подключение (relay, Маки, QR для нового Мака) · Claude (профиль, вид, быстрые ответы и шаблоны) · Терминал и код (шрифт, перенос) · Интеграции (GitLab, уведомления) · Опасная зона красным (Закрыть все сессии, Выйти).

### 5.12 Push и Live Activity — `LockScreen` (`mode`: push | live)
- Push: title и summary отчёта, кнопки действий = вопросы + «Ответить текстом…».
- Live Activity: проект, Мак, текущий инструмент, таймер, прогресс; Dynamic Island — точка статуса и время. Рядом — уведомление «Готово».

## Карта флоу (метрики брифа)

| Сценарий | Путь | Тапы |
|---|---|---|
| Проверить статус | Открыть → Входящие | 0 |
| Ответить на вопрос | Push → удержать → вариант | ≤ 2 |
| Посмотреть изменения | Отчёт «Diff ›» → изменения хода → файл | 2 |
| Новая задача | «Новая задача» → проект → текст/голос → Запустить | 3 + текст |
| Ревью MR | Ревью → MR → файл → строка → Approve | по ситуации |
| Аварийный терминал | Проект → «Терминал здесь» → ^C | 2 |

## Клавиатура — как реализовано

- Ни один экран не открывает клавиатуру сам: чат, терминал, новая задача, diff — только по явному тапу.
- Одна строка над клавиатурой (чат, терминал, новая задача, вход).
- «Спрятать» всегда в этой строке; в чате после отправки клавиатура закрывается.
- Шапка в режиме ввода сжимается до 32 pt.

## Работает в прототипе

Ответ из карточки с отменой · переход в чат · чипы и ответы в чате (появляется ход «работает») · «Ответить…» → клавиатура → отправка · «Diff ›» → diff → тап по строке → комментарий · новая задача: выбор проекта, режима, фокус на поле · терминал: открыть и спрятать клавиатуру · ревью: вкладки, MR → файл → diff · проекты: Маки → проекты → проект → файл · push: ответ с экрана блокировки · таб-бар.
