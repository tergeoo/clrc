Варианты · Входящие
Рекомендую 1a как основу и тайлы-счётчики из 1b на iPad.
1aПо срочности
Как в брифе: группы «Ждёт вас → Работает → Готово → Терминалы». Ответы прямо в карточке, FAB «Новая задача» под большим пальцем.
1bТриаж: одно следующее дело
Счётчики сверху, одна крупная карточка «Следующее» с большими кнопками, остальное — плотный список. Быстрее всего для 10-секундных сессий.
1cПо проектам
Ответ на вопрос 1: одна вкладка с переключателем «По статусу / По проектам». «＋» у проекта — новая задача в 1 тап.
Варианты · Чат
Режимы Chat и Brief — 2a и 2b. 2c — альтернатива: итог закреплён над полем ввода.
2aChat: текст, затем итог
Инструменты свёрнуты в одну строку. «4 файла · Diff ›» ведёт в diff хода. Внизу чипы быстрых ответов и пилюля «Ответить…» — клавиатура закрыта.
2bBrief: итог первым
Карточка итога сразу под сообщением, текст Claude свёрнут в «Подробности». Минимум прокрутки.
2cИтог закреплён внизу
Вопрос и кнопки ответа всегда в нижней трети, даже если лента прокручена к началу. Лента — только текст и код.
5.2 Входящие — состояния
Статус всех сессий без единого тапа. Ответ уходит сразу, 3 секунды на отмену.
5.2·1Ответ отправлен
Карточка переехала в «Работает», тост с отменой на месте FAB.
5.2·2Нет связи с relay
Баннер сверху, карточки — последняя известная версия, кнопки ответа неактивны.
5.2·3Пусто
Одна главная кнопка и недавние проекты — запуск в 1 тап.
5.2·4Загрузка
Скелетоны вместо спиннера на весь экран.
5.2·5Тёмная тема
Системная тёмная тема; цвета статусов — тёмные варианты iOS.
5.3 Новая задача
Мак → проект → режим. Тап по проекту при пустом поле — сразу запуск. Клавиатура только по тапу в поле.
5.3·1Шторка, без клавиатуры
Поле задачи не в фокусе. Главная кнопка — внизу.
5.3·2Ввод задачи
Шторка растёт до .large; Мак, проект и режим — строкой чипов над полем. «Запустить» — в панели над клавиатурой.
5.3·3Тёмная тема
5.4 Чат — клавиатура и состояния
Клавиатура не открывается при входе. С клавиатурой шапка сжимается до 32 pt, ввод + клавиатура ≈ 46 % высоты.
5.4·1Режим ввода
Одна строка над клавиатурой: спрятать, вложить путь/шаблон, поле, отправить. Свайп по ленте прячет клавиатуру.
5.4·2Claude работает
Живой индикатор в шапке, текущий инструмент в ленте, кнопка «Стоп» рядом с полем.
5.4·3Ошибка хода
Красная карточка, «Повторить» и «Сжать и продолжить».
5.4·4Тёмная тема
5.6 Терминал
Аварийный доступ. Клавиатура только по кнопке, одна строка спецклавиш, Ctrl залипает.
5.6·1Просмотр
13 pt, пинч-зум 10–18. Пути подчёркнуты — тап открывает файл.
5.6·2Ввод
Esc Tab Ctrl ↑↓←→ | ~ / - и «спрятать» — в одной строке 44 pt.
5.6·3Переподключение
Ввод заблокирован, вывод остаётся читаемым.
5.6·4Сессия завершена

5.8 Diff файла
Код всегда в тёмной палитре. Unified в портрете, split — в ландшафте на Pro Max. Word-diff, свёрнутые участки, мини-карта, обсуждения между строк.
5.8·4Pro Max, портрет
Навигация по ханкам и «Файл ›» — внизу. Тап по строке открывает комментарий.

Превью строки над полем, выделенная строка видна над шторкой.
5.8·6iPhone SE
11.5 pt, узкие колонки номеров; перенос включён.
5.8·7Pro Max, ландшафт — split
Старое слева, новое справа; комментарии — компактной строкой.
